## Data-quality rule

SOC-derived energy is an estimate. Short trips and integer SOC rounding can make the estimate unreliable; if the SOC delta cannot support a meaningful estimate, the UI should show unavailable/estimated state rather than fabricate precise consumption. Regenerative/downhill trips must not be forced into an invalid positive-consumption model.
