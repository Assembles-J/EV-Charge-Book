## Current State Consistency Rule

VehicleState is the current-state projection, not a replacement for historical facts.

- Charge / completed Trip events update current state.
- Backdated edits/deletes trigger state reconstruction from remaining valid events.
- Unknown historical values remain unknown.
- A later valid/manual current state must not be overwritten by an older event merely because that event was edited later.

## Data-Quality Rule

SOC-derived energy is an estimate, not BMS telemetry.

Short trips and integer SOC rounding can make the estimate unreliable. Regenerative/downhill driving or mid-trip charging can also cause unchanged/increased SOC. In those cases the UI must show unavailable/estimated state rather than force a precise consumption value.

GPS-derived mileage prefill is also an aid, not an odometer fact. Users can correct end mileage before completion.

Charge-side energy and Trip energy use different measurement semantics: charger/meter kWh is a recorded charging fact, while Trip kWh is a vehicle-side estimate inferred from configured battery capacity and SOC delta. They stay separated in Statistics.
