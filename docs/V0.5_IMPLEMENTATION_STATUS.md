## Smart Charging Flow — PR #81

Status: implemented, Android Build green.

Implemented:

- start SOC inherits current VehicleState, then falls back to the latest charge end SOC
- current mileage inherits VehicleState
- end SOC defaults to the previous charge end SOC, or 100 with no history
- five icon-distinguished charging types: 家充 / 公共慢充 / 公共快充 / 超充 / 闪充
- same-type recent unit price memory and recent charging presets
- billable charger/meter energy separated in the UX from vehicle-received energy
- vehicle-received energy derived from battery capacity and SOC delta
- charging loss estimate and anomaly warning
- total cost auto-calculation with manual override
- new charge automatically requests/uses current location, while retaining manual/common-place choices
- charge create/edit screens remove the large summary/Hero block and prioritize input
- charge completion updates current VehicleState SOC/mileage atomically
- charge edit/delete keeps charge-derived VehicleState consistent

## Trip SOC / Energy Flow — PR #84

Status: implemented foundation, Android Build green.

Implemented:

- trip start snapshots current VehicleState SOC/mileage
- Room schema 9 -> 10 adds trip start/end SOC, mileage, consumed energy and average consumption
- trip end requires end SOC
- end mileage is prefilled from start mileage + recorded GPS distance when available, and remains editable
- consumed energy is derived from battery capacity and SOC delta
- average consumption is derived as kWh/100km from consumed energy and recorded GPS distance
- trip completion updates current VehicleState SOC/mileage
- trip completion dialog previews SOC change, consumed kWh and average kWh/100km before save
- backup schema preserves the new trip fields and remains backward-readable
