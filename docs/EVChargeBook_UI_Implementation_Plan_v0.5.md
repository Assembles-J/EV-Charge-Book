# EV Charge Book v0.5 UI Implementation Plan

## Goal

Implement the approved Dark First design language while keeping v0.5 scope focused.

## Phase 1 Theme Foundation

- Define EV color tokens
- Unify dark surfaces
- Keep light theme compatibility
- Standardize spacing and typography
- Prepare reusable Compose components

## Phase 2 Dashboard

Transform Dashboard from metric cards into a vehicle-focused experience:

- Hero Vehicle Card
- Battery status
- Range display
- Monthly energy summary
- Recent charging activity

## Phase 3 Charging Timeline

Improve charging history readability:

- Timeline layout
- Charging type distinction
- SOC transition visualization
- Cost and energy emphasis

## Phase 4 Trip Experience

Trip becomes a key v0.5 feature:

- Route map card
- Start/end points
- Distance
- Duration
- Average speed
- Energy consumption
- Recent trips

## Phase 5 Analytics and Vehicle

- Energy dashboard refinement
- Vehicle profile refinement
- Dark/light switch

## Development Rule

Avoid introducing future features. Focus on polish, consistency, and maintainability.
