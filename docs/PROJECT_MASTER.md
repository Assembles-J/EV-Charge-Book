# EV Charge Book 项目总纲（PROJECT MASTER）

版本: v1.0.0

状态: Authority Document

## 1. 项目定位

EV Charge Book 是面向新能源车主的车辆充电记录、成本分析、电池健康管理 App。

核心目标:

- 记录真实充电数据
- 分析车辆使用成本
- 建立个人车辆数据资产

首个目标用户:

零跑 C16 车主。
